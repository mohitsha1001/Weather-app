# Weather-app

1. Designed and developed the frontend interface using React.js with HTML, CSS, and JavaScript.
2. Integrated OpenWeather API to fetch real-time weather data dynamically.
3. Implemented search functionality to allow users to look up weather by city name.
4. Developed responsive layouts for smooth user experience across devices.
5. Optimized API calls and error handling for better performance and reliability.
6. Documented project architecture and code to enhance maintainability and scalability.
